# 🚌 Bus Ticket Booking System

A web-based bus ticket booking system built with **ASP.NET Core MVC 6** and **SQL Server**.

## ✨ Features

- 👤 Two roles: **Admin** and **Passenger**
- 🔐 Secure authentication with email OTP password reset
- 🚌 Bus, route, schedule, and seat management
- 💺 Multi-seat booking (up to 5 seats per booking)
- 💳 Manual payment approval workflow
- 🎫 Ticket confirmation, printing, and QR code
- 📊 Admin dashboard with reports
- 🔍 Search and filter on all admin pages
- 🔄 Reschedule completed schedules

## 🛠️ Tech Stack

- ASP.NET Core MVC 6
- Entity Framework Core
- SQL Server
- Bootstrap 5
- Cookie Authentication
